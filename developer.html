About Me

Hello! I'm Raju, the creator of this Japanese Learner's Hub. As a fellow student of the Japanese language, I know the challenge of memorizing vocabulary. I built this tool to help myself and others in the Bangla-speaking community master N5 words in an interactive and efficient way.

My goal was to create a clean, modern, and useful application that you can personalize. I hope you find it helpful on your journey to learning Japanese!

Project Features

  • Dynamic Dictionary: Fetches all word and sentence data from a MongoDB database via serverless functions.
  • Offline-First: Core application data is cached locally, allowing for offline access and practice.
  • Personalization: Users can add, edit, and delete their own words, which are saved in their browser's local storage.
  • Interactive Admin Panel: A secure, feature-rich dashboard to manage the entire database, including bulk uploads and inline editing.
  • User Feedback Loop: Users can request missing example sentences, creating a direct channel for improving the dataset.
